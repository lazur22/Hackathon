# Divisão sugerida para 6 pessoas
1. **Tech lead / back-end** — domina `workflow.py`, resolve bugs de última hora, comanda o deploy.
2. **Integração** — legado, outbox, API de entrada; ensaia o cenário "queda do legado".
3. **Front-end gestor** — painel, indicadores, configuração; revisa acessibilidade.
4. **Mobile executor** — PWA, geolocalização, fotos, teste em celular real e HTTPS.
5. **IA e dados** — corpus, métricas do classificador, baseline real do Help Desk, slides de resultados.
6. **Produto / pitch** — roteiro, apresentação, documentação final, ensaios cronometrados e entrega (seção 18 do Manual).
Todos: ensaiar a demo 3× e ter um plano B gravado em vídeo.
